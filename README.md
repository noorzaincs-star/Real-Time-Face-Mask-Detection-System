# Real-Time Face Mask Detection System

A real-time face mask detection system built with deep learning and computer vision.

## Features
- Real-time face detection using computer vision
- Image classification model to detect mask / no mask
- Applied practical AI/ML concepts to a real-world problem

## Tools Used
- Python, [TensorFlow/Keras], [OpenCV]

## How to Run
1. Clone this repository.
2. Install requirements: `pip install -r requirements.txt`
3. Run: `python [main-file].py`
